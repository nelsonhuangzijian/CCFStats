# 1.0.0

- 在 Google Scholar 学者主页自动显示 CCF A／B／C／N 标签。
- 选择起止年份与等级后统计论文总数和一作数量；起止年份均为必选。
- 在已统计范围内切换年份立即更新结果；扩大至未统计年份时，点击 Update statistics 后补全新增部分，复用已有结果。
- 统计后可按所选等级、一作筛选论文，展示同色标签与左侧书签。
- 紧凑统计面板和弹窗，完成状态显示 Done x/y。
- 优先使用本地目录及缓存，支持常见书目信息和特定截断名称，包括 EMNLP。
- 通过 DBLP publication API 补全未确认刊物，使用共享队列、限速、缓存和失败重试。

仅统计当前已加载且属于所选年份范围的论文，不自动加载更多，也不请求 Scholar 搜索或论文详情页。

混合论文集按实际会议或轨道区分，不自动套用主会等级。例如 AAAI 38(21) 页码 23232–23240 属于 EAAI Symposium；[出版社记录](https://ojs.aaai.org/index.php/AAAI/article/view/30370)。

数据处理方式见[隐私政策](../PrivacyPolicy.md)。
